## 可采用的方向

- 浅色背景，整体安静。
- 内容区域居中，减少复杂导航和大面积边栏。
- 蓝色作为唯一主要强调色。
- 每个流程页只突出一个核心动作。
- 工作台保留项目管理能力，但视觉比当前原型更轻。
- Projects 页采用清晰项目列表，比当前大封面网格更适合管理。
- Idea 页的输入、生成结果、继续下一步节奏可以作为文案页参考。
- Voice 页的声纹/音色选择结构比当前音色库更聚焦。
- Avatar 页的大预览 + 右侧设置适合数字人页面。
- Render 页的视频预览 + 参数设置 + 时间线适合成片页面。
- Publish 页的平台发布包卡片适合后续发布包页面。

## 需要调整的地方

- 参考稿大量英文文案需要换成中文产品语义。
- 参考稿中的业务内容偏通用，需要替换为口播视频生产业务。
- 需要补足多音频、多视频、发布/未发布管理、AI 协同编辑能力。
- 当前正式项目已有 mock 数据和状态逻辑，不能直接照搬静态 HTML。
- 正式实现应吸收视觉和交互原则，而不是复制 CDN Tailwind 静态代码。

## 视觉原则

- 保留：浅色、留白、细边框、轻模块、蓝色主按钮、低噪声状态。
- 减少：强玻璃、强发光、重阴影、过多胶囊、封面卡片墙。
- 避免：纯聊天化、普通 SaaS 后台化、完整剪辑软件化。
