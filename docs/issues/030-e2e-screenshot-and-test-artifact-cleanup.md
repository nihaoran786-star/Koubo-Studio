# Issue 030 - E2E、截图测试和测试产物清理

## What to build

建立跨阶段 E2E、截图测试和测试产物清理机制，覆盖文本、音频、数字人、后期、发布页面。

## User pain

项目涉及大量本地文件、音频、视频和截图。如果没有测试产物清理，workspace 会快速污染；如果没有截图和 E2E，前端真实流程很容易回退。

## Acceptance criteria

- [ ] 每个阶段有最小 E2E 或截图测试策略。
- [ ] 测试 workspace 与真实用户 workspace 隔离。
- [ ] 测试音频、测试视频、截图、临时发布包有统一清理命令或清理流程。
- [ ] 测试失败时保留必要证据，并在报告中说明路径。
- [ ] 测试成功后删除临时产物。
- [ ] CI 或本地验证说明记录在文档中。
