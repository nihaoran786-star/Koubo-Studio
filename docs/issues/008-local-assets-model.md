# Issue 008 - 多音频多视频资产模型

## What to build

建立项目资产模型，支持脚本、参考音频、生成音频、数字人素材、字幕、封面、视频产物和平台导出版。

## User pain

真实作品通常有多个配音版本、背景音乐、字幕文件、横竖版视频、封面候选和平台导出版。当前 `Project` 模型太薄，无法登记、区分和复用这些资产。

## Acceptance criteria

- [ ] 项目支持 `audioAssets`、`videoAssets`、`subtitleAssets`、`coverAssets`、`publishPackages`。
- [ ] 每个资产记录本地路径、类型、来源、版本、创建时间、使用状态和关联步骤。
- [ ] 声音页可显示已导入/已生成音频，而不是只显示预设列表。
- [ ] 成片页选择的比例、字幕样式、背景音乐会写入渲染配置。
- [ ] 项目卡能根据真实缺口显示下一步，而不是统一写“声音 / 字幕待确认”。
