# Issue 010 - 真实发布包管理

## What to build

把发布页改成真实发布包准备工具。每个平台都有自己的标题、正文、标签、封面、视频文件、导出状态和操作记录。

## User pain

当前发布包只是动画卡片，复制、打开、导出都没有真实逻辑。运营无法知道抖音、小红书、视频号哪个已导出、哪个未发布、哪个需要重传。

## Acceptance criteria

- [ ] 每个平台有独立发布任务状态：未准备、准备中、已就绪、已导出、已发布、失败。
- [ ] 复制标题/正文/标签使用真实内容，并给出复制成功/失败反馈。
- [ ] 导出发布包会生成本地文件夹或 Markdown 文件。
- [ ] 打开按钮能打开平台发布页或本地发布包目录。
- [ ] 发布包状态回写项目列表。
