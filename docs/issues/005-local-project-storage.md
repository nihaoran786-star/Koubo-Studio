# Issue 005 - 建立真实本地项目库

## What to build

把工作台从静态 mock 项目改成真实本地项目库。用户新建、编辑、重启应用后，作品、当前步骤、脚本、资产引用和状态都必须能恢复。

## User pain

真实运营用户创建多条口播项目后，当前实现会因为 `PROJECTS` 常量和组件本地状态导致数据无法保存。文案页跨步骤卸载后也可能丢失刚编辑的内容。

## Acceptance criteria

- [ ] 新建作品会生成真实项目记录，而不是读取静态示例。
- [ ] 项目至少保存标题、平台、时长、当前步骤、更新时间、脚本草稿和状态。
- [ ] 用户刷新 Web 预览或重启桌面端后，项目列表和当前草稿可恢复。
- [ ] 首页示例数据必须标记为示例，或在已有真实项目时自动隐藏。
- [ ] UI 只通过项目库接口读取/写入，不直接操作 `localStorage` 或文件路径。

## Blocked by

None - can start immediately.
