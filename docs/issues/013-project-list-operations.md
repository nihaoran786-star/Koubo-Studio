# Issue 013 - 运营级项目列表操作

## What to build

增强项目页，让几十到几百条作品也可管理。支持搜索、排序、筛选、批量操作和异常项目优先级。

## User pain

当前项目页只有状态筛选，概览只展示前 4 个，当前任务直接取第一个制作中项目。真实运营会打开错项目，也无法批量处理未发布内容。

## Acceptance criteria

- [ ] 支持标题搜索。
- [ ] 支持按平台、状态、更新时间筛选/排序。
- [ ] 支持批量标记、批量导出发布包或批量删除草稿。
- [ ] 当前生产任务选择规则明确，例如最近编辑且未完成。
- [ ] 异常项目如渲染失败、发布失败优先显示。
