# Issue 007 - 首次打开与空项目首页

## What to build

为真实新用户提供空状态首页，而不是默认显示一堆已有作品和指标。首次打开应明确引导“创建第一条口播视频”。

## User pain

真实用户第一次打开看到当前生产任务、AI 待处理、生产队列和增长数据，会怀疑这是演示数据或别人的项目，不知道该从哪里开始。

## Acceptance criteria

- [ ] 没有真实项目时，首页显示创建第一条视频的主路径。
- [ ] 示例项目不得伪装成真实项目。
- [ ] 首页主按钮文案清晰，例如“创建第一条口播视频”。
- [ ] 设备检测不抢首次主线，只在声音/数字人或设置上下文中出现。
- [ ] 顶部导航用用户语言表达，例如“开始创作 / 我的作品 / 发布数据 / 设置”。
