# Issue 009 - 成片导出产物记录

## What to build

把“导出成片”从动画演示改成真实产物记录流程。即使暂时不接完整渲染引擎，也必须生成可追踪的导出任务和文件状态。

## User pain

运营点击导出后，目前只看到 `setTimeout` 模拟完成，没有 mp4 路径、文件大小、渲染日志、失败原因，也无法回到待发布视频库继续处理。

## Acceptance criteria

- [ ] 导出动作创建 `videoArtifact` 或 `renderJob` 记录。
- [ ] 产物记录包含本地路径、格式、比例、分辨率、时长、封面、字幕文件、音频轨、生成时间和校验状态。
- [ ] 渲染失败时显示明确原因和重试入口。
- [ ] 项目列表能区分待渲染、渲染中、渲染失败、已导出。
- [ ] 不再用固定 `/render-preview.png` 假装所有项目成片相同。
