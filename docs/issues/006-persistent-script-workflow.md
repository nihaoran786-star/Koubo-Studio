# Issue 006 - 文案流程保存与可恢复编辑

## What to build

把文案步骤从一次性聊天演示改成可恢复的脚本编辑流程。用户生成、手改、AI 改写、返回上一步后，所有文案块都必须保留。

## User pain

新手用户最怕“刚改好的稿子没了”。当前文案、聊天和编辑态都在 `IdeaChamber` 内部，切换步骤会卸载组件，真实生产不可接受。

## Acceptance criteria

- [ ] 文案状态提升为项目草稿的一部分，包含主题、平台、时长、风格、标题、开头钩子、口播正文、平台文案和标签。
- [ ] 每个文案块有常驻编辑入口，不依赖 hover 才能发现。
- [ ] 编辑支持保存/取消，不只依赖失焦。
- [ ] AI 改写后能显示变更提示，并支持撤销到上一版。
- [ ] 进入声音步骤前有明确主按钮：确认文案，选择声音。
